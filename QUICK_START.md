# 🚀 QUICK START - Push to GitHub in 3 Steps

## Step 1: Create GitHub Repository
1. Go to: **https://github.com/new**
2. Repository name: `robotics-portfolio`
3. Make it **PUBLIC**
4. Click **Create repository** (don't initialize anything)

## Step 2: Push Your Code
Copy & paste into Command Prompt/Terminal:

```bash
cd C:\Users\Prachi\Desktop\claude_project
git branch -M main
git remote add origin https://github.com/neelgheewala-005/robotics-portfolio.git
git push -u origin main
```

## Step 3: Enable Live Website (GitHub Pages)
1. Go to your repository: **https://github.com/neelgheewala-005/robotics-portfolio**
2. Click **Settings** (top right)
3. Scroll down to **Pages**
4. Select **main** branch
5. Wait 1-2 minutes
6. Your site: **https://neelgheewala-005.github.io/robotics-portfolio/**
