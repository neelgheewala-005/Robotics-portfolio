# Enable GitHub Pages - Final Step

Your code is now on GitHub! Now we need to enable GitHub Pages to make your portfolio website live.

## 🎯 Step 1: Go to Repository Settings

1. Open: **https://github.com/neelgheewala-005/Robotics-portfolio**
2. Click **"Settings"** tab (top right)

## 🎯 Step 2: Find Pages Section

1. On the left sidebar, scroll down and click **"Pages"**
2. You'll see a section that says "Build and deployment"

## 🎯 Step 3: Configure GitHub Pages

1. Under "Source", select **"Deploy from a branch"** (if not already selected)
2. Under "Branch", select:
   - Branch: **main**
   - Folder: **/(root)**
3. Click **"Save"** button

## 🎯 Step 4: Wait for Deployment

- Wait 1-2 minutes for GitHub to build and deploy
- You'll see a message: "Your site is published at..."

## ✅ Your Website Will Be Live At:
