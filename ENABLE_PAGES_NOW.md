## 🎯 ENABLE GITHUB PAGES (Takes 2 minutes)

### Click This Link:
```
https://github.com/neelgheewala-005/Robotics-portfolio/settings/pages
```

Or manually:
1. Go to: https://github.com/neelgheewala-005/Robotics-portfolio
2. Click **Settings** (top menu)
3. Click **Pages** (left sidebar)

### Then Follow These Steps:

**Step 1: Select Source**
- Click the dropdown under "Source"
- Select: **"Deploy from a branch"**

**Step 2: Select Branch**
- Branch dropdown: select **"main"**
- Folder dropdown: select **"/(root)"**

**Step 3: Save**
- Click the **"Save"** button

**Step 4: Wait**
- Wait 1-2 minutes
- Refresh the page
- You'll see: ✅ "Your site is published at..."

### Your Live URL Will Be:
```
https://neelgheewala-005.github.io/Robotics-portfolio/
```
