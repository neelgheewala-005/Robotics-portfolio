# Create GitHub Personal Access Token (1 minute)

Follow these steps to get a token so I can enable GitHub Pages for you automatically:

## Step 1: Open GitHub Token Page
Click this direct link:
👉 **https://github.com/settings/tokens/new**

Or:
1. Go to GitHub.com
2. Click your profile picture (top right) → **Settings**
3. Scroll down on left sidebar → **Developer settings**
4. Click **Personal access tokens** → **Tokens (classic)**
5. Click **Generate new token** → **Generate new token (classic)**

## Step 2: Fill in Token Details
- **Note / Name:** `Enable Pages` (or anything you want)
- **Expiration:** Choose `7 days` (or whatever you prefer)
- **Select scopes:** Check the box for **`repo`** (this gives full control of repositories)
  - It will automatically check all the sub-boxes under `repo`

## Step 3: Generate and Copy
1. Scroll to the bottom and click the green **"Generate token"** button
2. You'll see a page with your new token (starts with `ghp_...`)
3. **Copy the token** (click the clipboard icon)
   - ⚠️ Important: Copy it now, you won't be able to see it again!

## Step 4: Paste It Here
Once you have the token, paste it in the chat and I'll immediately enable GitHub Pages for your portfolio!
